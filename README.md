# darlow.me

Steve Darlow's personal link page — bio, projects, socials, contact.

- Plain static site: `index.html` (inline CSS/JS), no build step, no trackers, no cookies.
- Hosted on GitHub Pages from `main` (custom domain via `CNAME`).
- Dark "Liquid Glass" design: layered translucent glass, specular rims, pointer-tracked highlights,
  and true lens refraction on Chromium (SVG displacement maps in `backdrop-filter`); graceful blur fallback in Safari/Firefox.
  Honors reduced motion, reduced transparency, increased contrast and forced colors.

Edit a link: find its `<li>` in `index.html`. Icons live in `assets/icons/`. The share image is `og.png` (1200×630).
